## 工作循环(摘要,详见 03 文档)

架构师发包 → 开发 Agent 按任务书实施并自检 → 架构师七项门禁审核 → 通过则发包下一轮,不通过发整改清单 → 涉及游戏环境的验收项由用户真机执行并回填报告。
