# DH2 开发路线图

里程碑 → 迭代分解。每个迭代的任务包(任务书/技术设计/测试设计)由架构师在前序迭代审核通过后发包,本文档只锁定范围与验收方向,细则以迭代文档为准。

## 1. 里程碑总览

| 里程碑 | 目标 | 迭代 | 验收 |
|--------|------|------|------|
| M0 | 技术验证 + 工程骨架 | ITER-M0 | 最小闭环跑通;确定执行层路线(后台消息 or 焦点轮转) |
| M1 | 单开师门全自动 | M1a / M1b / M1c | 真机连跑 20 次师门无人工干预 |
| M2 | 多任务 + 调度 | M2a / M2b | 师门/帮派/修罗一键完成,断点续跑 |
| M3 | 五开编排 | M3a / M3b | 真机五开一条龙稳定跑通 |
| M4 | 监控与打磨 | M4a / M4b | 长期无人值守 + 告警 + 低成本维护工具链 |

## 2. 迭代分解

### ITER-M0 技术验证与工程骨架(3~5 天)
- 范围:解决方案骨架、窗口枚举、GDI 截屏、模板匹配、PostMessage 点击、CLI(`dh2ctl`)、MockGame v0、单元测试、clone 远端仓库并建 `iter/m0` 分支。
- 关键决策点:`[真机]` 验证游戏是否响应后台 PostMessage → 决定执行层路线。
- 详见 `iterations/M0/`。

### ITER-M1a 感知层完整化(1 周)
- 范围:ROI/锚点体系、场景分类器优先级链、模板 manifest 与热重载、WGC 截屏实现(可捕获遮挡窗口)、Windows.Media.Ocr 接入、DH2.Annotator v0(Avalonia,截图→框选→存模板)、金样本测试框架。
- 验收:金样本场景分类 100%;锚点定位误差 ≤2px;Annotator 产出可直接入库的模板。

### ITER-M1b 行为层与任务引擎(1 周)
- 范围:`IAtomicAction` 框架与首批原子操作(pathfind_to/click_ui/dialog_next/battle_auto)、FSM 引擎、YAML DSL v1 定稿、师门任务模板、MockGame v1(师门全流程模拟)。
- 验收:MockGame 上师门模板 20 轮全自动循环(L2);DSL 支持分支/循环/子流程。

### ITER-M1c Guardian 与单开闭环(1 周)
- 范围:弹窗守护、卡死检测恢复、Serilog 结构化上下文、SQLite(run_log/task_progress/error_snapshot)、`[真机]` 单开师门验收。
- 验收:**真机连跑师门 20 次无人工干预**;异常注入测试(弹窗/卡死)全部自动恢复或安全暂停。

### ITER-M2a 任务扩展与调度(1~2 周)
- 范围:帮派/修罗任务模板(含自动补蓝)、每日任务调度器、断点续跑、收益物品记录。
- 验收:单开三任务一键顺序完成;中断续跑正确。

### ITER-M2b 工具链与回放(1 周)
- 范围:Annotator 完善(版本化管理、批量重截)、L3 回放测试框架、真机金样本沉淀流程。
- 验收:模拟一次"游戏改版",2 小时内完成模板修复并通过回归。

### ITER-M3a 五开并行与编排(2 周)
- 范围:多 ActorSession 并行感知、Leader-Follower 协调器、BroadcastAsync、AsyncBarrier、五开布局管理。
- 验收:MockGame 五实例一条龙编排测试通过。

### ITER-M3b 五开韧性与真机验收(1~2 周)
- 范围:掉线重连归队、Follower 独立恢复、`[真机]` 五开一条龙验收。
- 验收:**真机五开稳定跑通一条龙**;单 Follower 异常不影响整体。

### ITER-M4a 监控台与告警(1~2 周)
- 范围:Avalonia 监控台(五窗缩略图/状态/日志流/启停)、Bark·Server酱告警、Quartz 周历调度。
- 验收:无人值守运行,异常手机可收到。

### ITER-M4b 收尾打磨(持续)
- 范围:ASP.NET Core Web 面板(可选)、性能优化、文档完善、使用手册。
- 验收:交接文档齐全,新维护者可上手。

```
M0 ─▶ M1a ─▶ M1b ─▶ M1c ─▶ M2a ─▶ M3a ─▶ M3b ─▶ M4a ─▶ M4b
                └────▶ M2b(可与 M2a/M3a 并行发包)
```

## 4. 里程碑级风险关卡

- **M0 出口关卡**:后台消息真机验证结论。失败 → 架构师修订 02 文档执行层章节(全局焦点轮转),M1+ 设计相应调整,工期 +1~2 周。
- **M1c 出口关卡**:真机师门闭环。识别准确率不达标 → 优先投入模板与金样本,而非推进新功能。
- **M3b 出口关卡**:五开稳定性。长时间运行内存/句柄泄漏 → 专项稳定性迭代。
