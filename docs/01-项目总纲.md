# DH2 项目总纲

| 项 | 内容 |
|---|---|
| 项目 | 大话西游2免费版 五开日常辅助工具 |
| 远端仓库 | https://github.com/DreamALittle/DahuaOnlineSupport.git |
| 技术栈 | C# / .NET 10 (LTS) / Avalonia UI / OpenCvSharp4 / Win32 P/Invoke |
| 文档版本 | v1.2(2026-09-20,接入远端仓库 + TFM net10 修订) |

## 1. 项目定位

纯外部视觉自动化工具:通过截屏识别游戏画面、向游戏窗口发送模拟鼠标键盘消息,自动完成日常任务。等价于"会看屏幕、会思考的按键精灵"。

## 2. 功能范围

1. **师门任务**:自动接取、类型识别(打怪/寻物/拜访)、执行、交付、循环至次数完成。
2. **帮派任务**:同构流程,场景与 NPC 不同。
3. **修罗任务**:组队、挂机自动战斗(含自动补蓝)、结算、循环。
4. **周常一条龙**:按周历调度上述任务,记录进度,支持断点续跑。
5. **五开编排**:Leader-Follower 模型,队长决策、队员镜像,统一处理游戏自带的"五开自动确认"之外的交互。

## 3. 技术红线(强制,违反即审核不通过)

**禁止以下任何一项出现在代码中:**

- 读写游戏进程内存(ReadProcessMemory / WriteProcessMemory / OpenProcess+VM_* / VirtualAllocEx / CreateRemoteThread / DLL 注入);
- 拦截、伪造、修改网络封包(原始套接字嗅探、Hook winsock、代理劫持);
- 修改游戏文件、游戏配置校验、反外挂检测逻辑;
- 加速、瞬移、复制等破坏游戏数值的功能;
- 自动化检测规避类设计(如专门模拟人类操作指纹以绕过风控)。

**合规约束:**

- 工具仅限个人自用,不分发、不售卖;
- 使用自动化违反游戏用户协议,存在封号风险且无法根除,风险由使用者承担;
- 依赖的游戏内置能力:自动寻路(点击任务追踪栏)、五开自动确认。

## 4. 角色与职责

| 角色 | 职责 | 产出 |
|---|---|---|
| **架构师 Agent**(本项目文档作者) | 规划、迭代任务书与技术细则、测试设计、审核、发放下一轮迭代 | docs/ 全部文档、审核报告 |
| **开发 Agent** | 按迭代文档编码、写测试、执行测试、自检 | 代码、测试、实施自检报告 |
| **用户** | 真机验证(需游戏环境的验证项)、决策 | 真机验证报告回填 |

## 5. 依赖的游戏内置能力

- 任务追踪栏点击自动寻路(主要移动方式,不自研寻路);
- 五开自动确认(组队/战斗确认由游戏代劳,工具只补不支持的场景);
- 自动战斗设置(战斗内挂机)。

## 6. 术语表

| 术语 | 含义 |
|---|---|
| ActorSession | 一个游戏窗口绑定的会话对象:窗口句柄+角色配置+感知上下文+任务状态机实例 |
| ROI | Region of Interest,屏幕上按语义划分的识别区域(任务追踪栏/对话区/战斗指令区/小地图/血蓝条) |
| 锚点 | 固定 UI 元素(如任务栏边框),所有坐标相对锚点计算,抗窗口位移与分辨率差异 |
| 模板库 | templates/ 目录下的截图模板 + manifest.yaml(阈值/点击偏移/版本) |
| 场景分类器 | 判定当前画面处于 掉线/弹窗/战斗/对话/寻路/待机 的优先级链 |
| Guardian | 守护子系统:弹窗处理、卡死检测恢复、断线重连 |
| Leader-Follower | 五开编排模型:队长窗口决策,队员窗口镜像执行 |
| 一条龙 | 周常任务按计划顺序自动执行的总称 |
| MockGame | Avalonia 模拟游戏窗体,供无游戏环境下开发与自动化测试 |
| 真机验证 | 需要真实游戏环境、由用户执行的验证项 |

## 7. 非目标(明确不做)

- 多用户/云端服务化;
- 任何形式的内存/封包级外挂;
- 自动交易、摆摊定价、商业化收益行为;
- 跨游戏通用化抽象。
