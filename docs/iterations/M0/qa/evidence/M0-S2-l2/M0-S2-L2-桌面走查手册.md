### 5.2 **人工点击 MockGame 窗口中的"前往"按钮**

操作:
- 把 MockGame 窗口调到前台(点击标题栏)
- 点击"前往"按钮(在客户区 (86, 204) 附近 ±10px)

### 5.3 等待状态转移 Pathfinding → Arrived

```powershell
$timeout = (Get-Date).AddSeconds(5)  # M0 约定 Pathfinding 持续 ~2s
$prevState = $null
while ((Get-Date) -lt $timeout) {
    $state = (Get-Content $StateFile -Raw | ConvertFrom-Json).state
    if ($state -ne $prevState) {
        Write-Host "state -> $state"
        $prevState = $state
    }
    if ($state -eq 'Arrived') { break }
    Start-Sleep -Milliseconds 200
}

Copy-Item $StateFile "$ResultsDir\05b-state-arrived.json" -Force
Copy-Item $MsgLog "$ResultsDir\05b-messages-arrived.log" -Force

# 验证 state 已到 Arrived
$finalState = (Get-Content $StateFile -Raw | ConvertFrom-Json)
if ($finalState.state -ne 'Arrived') {
    Write-Error "未达 Arrived,实际 $finalState"
}
```

**期望**:`state.json.state == "Arrived"`,button text 应为 "返回"(视觉确认)

### 5.4 验证双路日志(messages.log 同时含 `|raw|` 与 `|ui|` 行)

```powershell
$logContent = Get-Content "$ResultsDir\05b-messages-arrived.log" -Raw
$rawCount = ([regex]::Matches($logContent, '\|raw\|')).Count
$uiCount = ([regex]::Matches($logContent, '\|ui\|')).Count

Write-Host "raw 行数: $rawCount"
Write-Host "ui 行数: $uiCount"

if ($rawCount -lt 1) { Write-Error "无 |raw| 行(WM_LBUTTONDOWN/UP 子类化钩子未触发)" }
if ($uiCount -lt 1) { Write-Error "无 |ui| 行(Avalonia PointerPressed/Released 未触发)" }
```

**期望**:`raw` 行 ≥ 1(WM_LBUTTONDOWN 0x201 或 WM_LBUTTONUP 0x202),`ui` 行 ≥ 1(PointerPressed/Released)

### 5.5 **第二次人工点击 MockGame 窗口中的"返回"按钮**

等待 ~1s 让界面刷新,然后点击"返回"按钮(同一位置附近,按钮文字已变)

**期望**:`state.json.state == "Idle"`,`counter` 比初始值大 1(若初始 0,则现在 1)

## 步骤 6 — 关闭 MockGame + 退出确认

```powershell
# 1) 发送关闭信号(优雅退出优先)
Get-Process DH2.MockGame -ErrorAction SilentlyContinue | Stop-Process -Force
Write-Host "MockGame 已发送关闭信号"

# 2) 确认进程已退出(架构师 S2 审核 §5 要求:实测存在孤儿进程残留风险)
$timeout = (Get-Date).AddSeconds(10)
while ((Get-Date) -lt $timeout) {
    $proc = Get-Process DH2.MockGame -ErrorAction SilentlyContinue
    if (-not $proc) {
        Write-Host "MockGame 进程已退出"
        break
    }
    Start-Sleep -Milliseconds 500
}
$stillRunning = Get-Process DH2.MockGame -ErrorAction SilentlyContinue
if ($stillRunning) {
    Write-Warning "MockGame 进程仍在运行(孤儿),PID: $($stillRunning.Id) — 可能影响下次走查"
    Write-Warning "请手动结束或重启桌面会话"
} else {
    Write-Host "退出确认 PASS"
}
```

**期望**:
- 退出码 0
- 输出含 "退出确认 PASS"
- 若打印 Warning,记录到 `results\anomalies.txt` 并通知 QA

## 异常处置

- **步骤 3 输出 0 条**:窗口被遮挡 / MockGame 未真正启动 / dev.yaml 的 TitlePattern 不匹配。检查 dev.yaml 的 targets 与 MockGame 实际 Title
- **步骤 4 帧数 ≠ 10 或文件大小 = 0**:窗口可能被最小化或遮挡,需保持 MockGame 在前台可见
- **步骤 5.4 双路日志缺失**:汇报 raw/ui 行计数给 QA;若 raw=0 → SetWindowSubclass 未触发;若 ui=0 → Avalonia Pointer 事件未触发
- **MockGame 启动崩溃**:检查 `artifacts\logs\` 下是否有 Serilog 日志,把关键异常给 QA / 架构师

> ⚠️ 若任一步骤结果与期望不符,**不要静默继续**——把异常记录到 `results\anomalies.txt`,
> 完成后一并回传 QA,由 QA + 架构师决定是否开 DEF 或回滚。
