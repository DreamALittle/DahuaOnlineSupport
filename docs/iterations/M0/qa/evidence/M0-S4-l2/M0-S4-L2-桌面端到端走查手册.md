## 步骤 1 — 启动 MockGame(后台,清空 state.json 模拟 fresh start)

```powershell
$MockGameExe = 'D:\Repos\DH2-QA\artifacts\bin\DH2.MockGame\release\DH2.MockGame.exe'
$ResultsDir = 'D:\Repos\DH2-QA\docs\iterations\M0\qa\evidence/M0-S4-l2/results'
New-Item -ItemType Directory -Path $ResultsDir -Force | Out-Null

# 删除旧 state.json,确保 counter 从 0 开始
$TempDir = Join-Path $env:TEMP 'dh2-mockgame'
if (Test-Path $TempDir) { Remove-Item $TempDir -Recurse -Force }

Start-Process -FilePath $MockGameExe -PassThru | ForEach-Object {
    $_.Id | Out-File "$ResultsDir\mockgame.pid.txt"
    Write-Host "MockGame started, PID: $($_.Id)"
}

# 等待 state.json 出现 + state=Idle
$StateFile = Join-Path $TempDir 'state.json'
$timeout = (Get-Date).AddSeconds(15)
while ((-not (Test-Path $StateFile) -or ((Get-Content $StateFile -Raw | ConvertFrom-Json).state -ne 'Idle')) -and (Get-Date) -lt $timeout) {
    Start-Sleep -Milliseconds 200
}
if (-not (Test-Path $StateFile)) {
    Write-Error "state.json 未出现,MockGame 可能未启动"
    exit 1
}
Get-Content $StateFile -Raw | Out-File "$ResultsDir\01-state-initial.json"
Write-Host "MockGame Idle"
```

**期望**:`{"state":"Idle","counter":0,"ts":"..."}`(counter=0,fresh start)。

## IT-04 — click 后 raw 日志 0x201/0x202 + state 转移 Pathfinding

### 4.1 截取 messages.log 当前内容(基线)

```powershell
$MsgLog = Join-Path $TempDir 'messages.log'
if (Test-Path $MsgLog) {
    Copy-Item $MsgLog "$ResultsDir\04a-messages-pre-click.log" -Force
} else {
    Write-Warning "messages.log 不存在(MockGame 启动尚未产生)"
    New-Item -ItemType File -Path "$ResultsDir\04a-messages-pre-click.log" -Force | Out-Null
}
```

### 4.2 dh2ctl click + 截屏 messages.log 增量

```powershell
# 按钮中心坐标(逻辑 DIP @100% 缩放):按钮几何 (16, 180, 140, 48) → 中心 (86, 204)
& $Dh2CtlExe click --hwnd $Hwnd --x 86 --y 204 2>&1 |
    Tee-Object -FilePath "$ResultsDir\04b-click-taskbar.json" | Out-Host

# 等待 1s 让 MockGame 处理 click 并把 0x201/0x202 写入 messages.log
Start-Sleep -Seconds 1

# 截取 messages.log 增量
if (Test-Path $MsgLog) {
    Copy-Item $MsgLog "$ResultsDir\04c-messages-post-click.log" -Force
}
```

**期望**:
- stdout 一行 JSON:`{"success":true,"attempts":1,"failReason":""}`(退出码 0)
- messages.log 在 click 后 1s 内出现至少一对 `0x0201`(LBUTTONDOWN)+ `0x0202`(LBUTTONUP)行
  (raw input 监听被 MockGame 触发)

### 4.3 等待 state 转移 Idle → Pathfinding

```powershell
$timeout = (Get-Date).AddSeconds(3)
$prevState = $null
while ((Get-Date) -lt $timeout) {
    $state = (Get-Content $StateFile -Raw | ConvertFrom-Json).state
    if ($state -ne $prevState) {
        Write-Host "state -> $state"
        $prevState = $state
        Get-Content $StateFile -Raw | Out-File "$ResultsDir\04d-state-$state.json"
    }
    if ($state -eq 'Pathfinding' -or $state -eq 'Arrived') { break }
    Start-Sleep -Milliseconds 200
}
```

**期望**:`state -> Pathfinding` 出现(state.json 文件被复制到 results)。

### 4.4 等待 Pathfinding → Arrived

```powershell
$timeout = (Get-Date).AddSeconds(5)  # M0 约定 pathfindingMs=2000 + 缓冲
while ((Get-Date) -lt $timeout) {
    $state = (Get-Content $StateFile -Raw | ConvertFrom-Json).state
    if ($state -eq 'Arrived') {
        Write-Host "state -> Arrived"
        Get-Content $StateFile -Raw | Out-File "$ResultsDir\04e-state-arrived.json"
        break
    }
    Start-Sleep -Milliseconds 200
}
```

**期望**:`state -> Arrived` 出现(2 秒内 Pathfinding 自然转移完成)。

## IT-06 — 再次点击回 Idle + counter 递增

### 6.1 二次 click + state 转移 Arrived → Pathfinding → Arrived

```powershell
# 状态当前应为 Arrived;再次点击"返回"按钮(同区域中心)
& $Dh2CtlExe click --hwnd $Hwnd --x 86 --y 204 2>&1 |
    Tee-Object -FilePath "$ResultsDir\06a-click-return.json" | Out-Host

Start-Sleep -Seconds 1

# 等待 Pathfinding → Arrived(再次完整循环)
$timeout = (Get-Date).AddSeconds(5)
while ((Get-Date) -lt $timeout) {
    $state = (Get-Content $StateFile -Raw | ConvertFrom-Json).state
    if ($state -eq 'Pathfinding') {
        Get-Content $StateFile -Raw | Out-File "$ResultsDir\06b-state-pathfinding.json"
    }
    if ($state -eq 'Arrived') {
        Write-Host "state -> Arrived (2nd cycle)"
        Get-Content $StateFile -Raw | Out-File "$ResultsDir\06c-state-arrived-2nd.json"
        break
    }
    Start-Sleep -Milliseconds 200
}
```

### 6.2 第三次 click 回 Idle + counter 递增断言

```powershell
$BeforeCounter = (Get-Content $StateFile -Raw | ConvertFrom-Json).counter
Write-Host "counter before: $BeforeCounter"

& $Dh2CtlExe click --hwnd $Hwnd --x 86 --y 204 2>&1 |
    Tee-Object -FilePath "$ResultsDir\06d-click-third.json" | Out-Host

# 等待回 Idle
$timeout = (Get-Date).AddSeconds(5)
while ((Get-Date) -lt $timeout) {
    $state = (Get-Content $StateFile -Raw | ConvertFrom-Json).state
    if ($state -eq 'Idle') {
        Write-Host "state -> Idle (3rd cycle)"
        Get-Content $StateFile -Raw | Out-File "$ResultsDir\06e-state-idle-3rd.json"
        break
    }
    Start-Sleep -Milliseconds 200
}

$AfterCounter = (Get-Content $StateFile -Raw | ConvertFrom-Json).counter
Write-Host "counter after: $AfterCounter"
"$BeforeCounter -> $AfterCounter" | Out-File "$ResultsDir\06f-counter-delta.txt"

# 断言:counter 应 +1(从 Arrived 回 Idle 计一次点击)
if ($AfterCounter -ne ($BeforeCounter + 1)) {
    Write-Error "counter 未递增: $BeforeCounter -> $AfterCounter(期望 +1)"
    exit 1
}
```

**期望**:`counter after - counter before == 1`(每次 Arrived → Idle 计一次点击)。

## IT-05 — `dh2ctl e2e --target mock` 全链路

### 5.1 重启 MockGame 到 Idle(fresh)

```powershell
$MockGamePid = Get-Content "$ResultsDir\mockgame.pid.txt"
Stop-Process -Id $MockGamePid -Force
Start-Sleep -Seconds 1

Remove-Item $TempDir -Recurse -Force
Start-Process -FilePath $MockGameExe -PassThru | ForEach-Object {
    $_.Id | Out-File "$ResultsDir\mockgame.pid.txt"
}
$timeout = (Get-Date).AddSeconds(15)
while ((-not (Test-Path $StateFile) -or ((Get-Content $StateFile -Raw | ConvertFrom-Json).state -ne 'Idle')) -and (Get-Date) -lt $timeout) {
    Start-Sleep -Milliseconds 200
}
Get-Content $StateFile -Raw | Out-File "$ResultsDir\05a-state-fresh.json"
Write-Host "MockGame fresh start → Idle"
```

### 5.2 dh2ctl e2e --target mock

```powershell
& $Dh2CtlExe e2e --target mock --config configs\dev.yaml 2>&1 |
    Tee-Object -FilePath "$ResultsDir\05b-e2e-output.txt" | Out-Host
$exit = $LASTEXITCODE
Write-Host "exit=$exit"
$exit | Out-File "$ResultsDir\05c-e2e-exit.txt"
```

**期望**:
- 退出码 = 0
- 输出包含 `E2E: PASS`(dev-b/m0-s4 E2eCommand 设计 §6.1)
- `artifacts/e2e-{ts}/` 目录包含:
  - `frame_before.png`(截屏前)
  - `state_ensure_idle.json`(初始 Idle)
  - 二次截屏后 `match` JSON 输出
  - `state_*.json`(状态转移记录)
- 用户视觉确认 MockGame 实际点击并完成了 Idle → Pathfinding → Arrived → Idle 全循环
